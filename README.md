# Student Data Cleaning and Preparation

## Project Overview
This project focuses on cleaning and preparing a student dataset using Python and Pandas.

## Tasks Performed
- Loaded the student dataset into Pandas.
- Checked the number of rows and columns.
- Checked for missing values.
- Checked for duplicate rows.
- Saved the dataset as a CSV file.

## Tools Used
- Python
- Pandas
- Google Colab
- GitHub

## Output
The cleaned dataset is saved as `cleaned_student_data.csv`.# student-data-cleaning-2026
